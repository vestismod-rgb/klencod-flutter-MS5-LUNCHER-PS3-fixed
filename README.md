# MS5 LUNCHER (PS3 .pkg)

واجهة ألعاب لجهاز PS3 بتصميم شريط أفقي، تعرض أربعة أقسام:

| القسم | من أين يقرأ | كيف يشغّل |
|---|---|---|
| ملتي مان | `GAMES` و`GAMEZ` على `/dev_hdd0` وكل منافذ `/dev_usb00x` | عبر webMAN MOD |
| ISO | `PS3ISO` على القرص وUSB (يقرأ الاسم من داخل ملف ISO) | عبر webMAN MOD |
| PKG | الألعاب المثبّتة من حزم في `/dev_hdd0/game` (أرقام مثل `BLES`/`NPUB`) | عبر webMAN MOD |
| التطبيقات | بقية البرامج المثبّتة في `/dev_hdd0/game` | مباشرة (`EBOOT.BIN`) |

## الأزرار
* **O** تأكيد (وتظهر نافذة تأكيد قبل التشغيل)
* **X** رجوع (من القائمة الرئيسية يسأل عن الخروج)
* الأسهم: تنقّل بين العناصر، و**L1/R1** (أو ↑↓) بين الأقسام

## البناء على GitHub
1. أنشئ مستودعاً جديداً وارفع كل محتويات هذا المجلد (بما فيها `.github`).
2. افتح تبويب **Actions**. أول تشغيل يبني أدوات ps3dev ويستغرق نحو ساعة، ثم تُحفظ في الذاكرة المؤقتة فتصبح التشغيلات التالية سريعة.
3. من صفحة التشغيل نزّل **MS5Luncher-pkg** (فيها `MS5Luncher.pkg`).
4. لإنشاء إصدار تلقائي: `git tag v1.0 && git push --tags`.

## التثبيت
انسخ الملف `.pkg` إلى USB ثم ثبّته من XMB (Package Manager ← Install Package Files)، أو بأي مدير ملفات عندك.

## ملاحظات مهمة
* التشغيل يحتاج **CFW/HEN مع webMAN MOD**. التطبيقات تعمل بدونه.
* الألعاب من نوع ملتي مان وISO تُركَّب أولاً (`/mount_ps3`) ثم يُطلب تشغيلها (`/play.ps3`). إن لم تبدأ تلقائياً ستجدها مركّبة في XMB في عمود الألعاب.
* الأزرار O/X مضبوطة كما طلبت (تأكيد/رجوع) داخل البرنامج نفسه.

## الاختبار والتطوير
* `python3 test/make_fake_root.py /tmp/fakeps3` ثم `gcc ... test/host_main.c ...` (انظر `.github/workflows/build.yml`) لتشغيل الواجهة على الكمبيوتر وحفظ لقطات PPM.
* النصوص العربية والإنجليزية مرسومة مسبقاً في `source/textdata.c`. لتغيير نص عدّل `tools/gen_text.py` وشغّله.
* الصور العشوائية للألعاب مولّدة من اسم اللعبة، ولا تستخدم أغلفة الألعاب الأصلية.

## الخط والتصميم (MS5)
- التصميم الآن بنمط MS5: خلفية زرقاء بأمواج متحركة وتوهج حول العنصر المحدد.
- الخط Tajawal يُنزَّل تلقائياً في GitHub Actions (`tools/fetch_fonts.sh`) ثم يُولَّد `textdata.c`. لتجربته محلياً: `tools/fetch_fonts.sh && python3 tools/gen_text.py`.
- الملف `textdata.c` المرفق في الـ zip ما زال بخط DejaVu المؤقت؛ سيُستبدل بـ Tajawal عند البناء على GitHub.

## الأقسام (على نمط MS5)
التبويبات: **الألعاب** (ملتي مان + ISO + PKG معاً) · **التطبيقات** · **وسائط** · **الإعدادات** · **المتجر** · **الملفات**. التنقل بين التبويبات بـ L1/R1.

- **اختيار المستخدم:** تظهر شاشة «من يستخدم؟» عند البدء (يمكن إيقافها من الإعدادات > عام). يمكن إضافة حتى 4 مستخدمين.
- **الألعاب/التطبيقات:** مثلث (Triangle) يفتح قائمة «إضافة إلى التطبيقات / الألعاب» لنقل العنصر بين القسمين. تُحفظ في `moves.cfg`.
- **وسائط:** فيديو/موسيقى/صور تفتح مجلداتها في الملفات (`/dev_hdd0/video` و`music` و`photo`). المتصفح غير متوفر.
- **الإعدادات:** ثلاث فئات: المستخدم (تبديل/إضافة/حذف)، عام (اللغة عربي/English، سرعة الحركة، حركة الخلفية، نظام 24 ساعة، السؤال عند البدء، تأكيد قبل التشغيل)، المظهر (لون الخلفية، شفافية اللوحات، تعتيم، الأمواج، لون التمييز، حجم واستدارة الأيقونات، إعادة الضبط). تُحفظ فوراً في `/dev_hdd0/game/MS5LNCHR1/USRDIR/settings.cfg`.
- **الملفات:** تصفح حقيقي للقرص وUSB. O دخول، X رجوع، مربع تحديد، مثلث قائمة (حذف / تحديد الكل / إلغاء). لا يُحذف جذر الأجهزة، والمجلدات غير الفارغة لا تُحذف.
- **المتجر:** كتالوج محلي من `USRDIR/store.txt` (سطر لكل عنصر: `الاسم|الوصف|النوع|الحجم`) مع تصفية بمثلث. التثبيت غير متاح بعد.

غير موجود مقارنة بنسخة الويب: كلمة مرور المستخدم، الصور الشخصية، صور الخلفية، أصوات التنقل، شريط مساحة التخزين، البحث في المتجر.
