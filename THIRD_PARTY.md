# Third-party notes

* The glyph bitmaps in `source/textdata.c` were rendered from **DejaVu Sans** (Bitstream Vera / DejaVu licence,
  which allows embedding and redistribution). Regenerate with `python3 tools/gen_text.py`.
* Built with **PSL1GHT** (MIT) and the **ps3dev** toolchain.
* Game launching uses the optional **webMAN MOD** HTTP interface running on the console.

## Tajawal font
Tajawal by Boutros Fonts, licensed under the SIL Open Font License 1.1. Downloaded at build time from google/fonts and baked into `source/textdata.c` as bitmaps.
